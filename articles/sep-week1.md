# 【朝活ブログ部 交流会レポート】8月の数字をその場で分析して、9月にやることを決めた話

2026年9月3日(木)、朝活ブログ部の9月1週目の交流会を開催しました！
9月からは、交流会の型を「1週目＝分析と作戦」「2週目＝その実作業」「3週目＝添削と雑談」「4週目＝添削会」に固定しています。今回はその1週目ということで、主催ブログの8月の数字(ASPのクリック数・サーチコンソール・Clarity・AIの月次分析)を、事前に用意せずその場で見ながら、9月の作戦候補を出して本命を決めていきました。

議事録ベースで、当日見ていった数字の流れに沿ってまとめましたので参考にしてくださいね。

## 先月の作戦は、どうなった？

まず8月1週目の交流会で決めた作戦の答え合わせからです。

8月は「表示がいちばん多い主力記事なのに、広告クリックがいちばん少ない。SEOではなく記事の中の導線の問題」という課題を挙げていました。

結果としては、読まれる量はしっかり伸びました。

*   検索クリック数：58 → 104
*   表示回数：1,264 → 2,305
*   平均CTR：4.59% → 4.51%(横ばい)
*   平均掲載順位：8.5 → 8.3

一方で、肝心の主力記事の広告クリックは月2件のままでした。
8月は主力記事に計測用のタグを入れて効果を測っている期間だったので、本文を触れなかったんです。触っていないので数字も動かない、という当たり前の結果ですね。

成果のほうは、8月に1件(2,000円)発生したもののキャンセルになり、確定は0円のままでした。

ただ、2か月連続で発生が出ているので、あとは打率を上げていく話になります。4件発生すれば1件は確定するかもしれない、というイメージですね。
何も発生していないと「どれに手をつければいいか分からない」状態が続くので、発生が出ている案件に注力できるようになったのは、光が見えたとも言えます。

## そもそも先月の振り返り、やりましたか？

冒頭で「みなさん8月の振り返りはしましたか？」と聞いてみました。

「AIにサーチコンソールのデータを渡して、ざっくりの振り返りはしている」という方もいれば、「していない」という方もいました。

正直なところ、振り返るより新しい記事を書いて前に進むほうが、心理的には絶対に楽なんですよね。
毎日記事を書いているほうが「やった感」もあります。

でも、その記事を書いている方向が**崖に向かっているのか、ゴールに向かっているのか**で全然違います。

自分も知識を入れずに書いていた頃は、100記事、200記事とゴミ記事を増やしていました。
その黒歴史が分かったのは、振り返ったからです。振り返らないと、黒歴史は黒のままなんですよね。しかも本人が気づいていない状態です。

なので、振り返りは月1回でも2か月に1回でもいいので、やったほうがいいです。
積み上げているけど「この道は合っているのか？」と不安になる人ほど、数字を見ると意外と最短ルートが見えてきます。数字は嘘をつかないので。

## 8月にやったこと

主催ブログの8月の作業はこんな感じでした。

*   新記事16本を公開(18記事 → 34記事)
*   主力記事に広告の表示回数を測るタグを設置
*   新しい案件2件の提携申請(現在も再審査待ち)
*   分析・戦略整理(週次チェック・カニバリ調査・上位サイト調査)

4月開設なので、ちょうど5か月弱のブログです。

## ASPのクリック数は、7月からおおむね右肩上がり

最初にASPの管理画面から、案件ごとの表示回数(インプレッション)とクリック数を見ていきました。

インプレッションは「広告が読者の画面に表示された回数」、クリック数は「そのアフィリエイトリンクが押された回数」です。

8月は、主要な案件で表示194・クリック29、別の案件で表示137・クリック17と、7月に比べて数字がかなり増えていました。
新しく追加した案件も表示10・クリック2と、少しずつ動き始めています。

ここで見るポイントは2つです。

*   **クリック数が多い案件から、リライトやKWの再選定をする**。読者がゴールの手前まで来てくれている案件なので、テコ入れの効果が出やすい
*   **表示は多いのにクリックが少ない案件は、リンクの置き場所・個数・ボタンの色・文言・マイクロコピーを見直す**

サーチコンソールはあくまで「記事に来る前」の数字ですが、ASPのクリックは「記事に来て、なおかつリンクを押してくれた」という、ほぼゴール直前の数字です。
だからベースとしては、**成果が発生している記事からテコ入れするのがいちばん早い**という話になります。

## サーチコンソールは「表示回数順」と「クリック数順」で2回並べ替える

次にサーチコンソールで、8月にどんな言葉で来たのかを見ていきました。

クエリ(検索された言葉)を**表示回数で並べ替える**と、いちばん多かったのは解約系の「○○」でした。
表示180回に対してクリックは1回、掲載順位は10.8位。1ページ目に入るか入らないかの位置です。

解約系は、もともと使っている人が「どうやってやめるのか」を調べているケースが大半なので、いわゆる今すぐ客ではありません。
ただ、定期便のようなサービスは縛りがあったり、電話でしか解約できなかったりします。「そういう制約があるなら別のサービスにしようかな」という層も一定数いるので、成果につながる可能性はゼロではない、という位置づけですね。

2番目に多かったのは、商品名に特徴を掛け合わせた「○○ △△」のような言葉で、掲載順位は3.9位。
上位はキープできているのですが、こういうふんわりした言葉は購買意欲と結びつきにくく、成果にするのは難易度が高めです。テコ入れはしつつ、様子見という感じです。

3番目は比較系の「○○ △△ 比較」でした。

比較系は、すでにどちらかに決めかけている人が「どっちがいいのか」を確認しにくる言葉です。
そして企業メディアは自社商品があるので、他社を下げるような比較記事を書きにくい。**個人ブログのほうが比較・どっち系は上位に入り込みやすい**と言われています。

理想は両方使った経験があることですが、片方だけでも、調べているうちに違いは分かってきます。
比較記事を読んでいる途中で「実際の中身はどうなの？」と気になったところに、実際に使った感想のレビュー記事へ内部リンクがあると、かなりプラスに働きます。

## クリック数順に並べ替えると、顔ぶれが変わる

今度は**クリック数で並べ替え**ます。すると、上位の顔ぶれが少し変わります。

ここで探すのが、**表示回数は3桁あるのにクリック数が1桁**の記事です。
さっきの解約系のように、180人が検索してくれたのに記事に来たのは1人、という状態ですね。

このとき、掲載順位も一緒に見ます。

*   **10位前後なら、リライト対象として優先度が高い**。そのKWで記事がすでに評価されているので、タイトルと冒頭を直すだけでクリックを回収できる
*   **34位のような2〜3ページ目は、リライトしても1ページ目まで上げるのは難易度が高い**。後回しでいい

「表示回数が多くてクリックが少ない記事から直す」はよく言われますが、順位を見ずにやると空振りしやすいので注意です。

## 記事には来ているのに、リンクが押されないとき

記事には来ている、でもアフィリエイトリンクがクリックされていない。
このときは、Microsoft Clarityで読者の動きを見ます。

読まれている記事のURLを指定して、**どこで止まっているか・どこをクリックしているか**を見るだけでOKです。

たとえばリード文で止まっているなら、じっくり読まれているということなので、そこに手を入れてみます。

*   4行だったリード文を5行にしてみる
*   2行目と3行目を入れ替えてみる
*   ボタンリンクにマイクロコピーを付けてみる
*   ボタンの色を、ブログ全体の色と被らない範囲で赤やオレンジに変えてみる
*   思い切ってボタンリンクをテキストリンクに変えてみる

1記事だけでもバリエーションは無限にあるので、困っちゃうくらいです。

読者に「買って買って」と押し売りしても買ってくれません。その商品を手に入れることで悩みが解消される、いい未来を見せるのが理想…とは言われるものの、「そんなの分かんない」となりますよね。
なので、まずはこういう小さな変更を1つずつ試すのが現実的です。

当日は主力記事のヒートマップも開いてみました。赤いところがよく押されている場所で、目次はかなりクリックされていましたし、記事内のリンクも押されていることが確認できました。

## 変えたら、必ず検証する。100%当たる施策はない

大事なのは、変えたあとの検証です。

1週間でも2週間でも1か月でもいいので、自分の中で期間を決めて、またサーチコンソールやASPの画面を見にいきます。

*   クリック率が上がっていれば、実験成功
*   横ばいなら、もう少し様子見
*   すごく下がったら、施策を変える

たとえば「表示回数が多いのにクリックが少ないから、タイトルが魅力的じゃないのかも」と考えてタイトルを変えたとします。
11位だった記事が、うまくいけば8位に上がる。うまくいかなければ15位に下がる。

下がった場合、そのときのアルゴリズムの影響もあるとは思いますが、自分が起こしたアクションはタイトル変更なので、いったん元に戻します。戻せば11位に戻るかというと、それもまた分からないのですが。

**この施策をやったからうまくいく、というものは100%ありません。**
だからこそ、うまくいった例・いかなかった例を自分の引き出しにして、また同じパターンが出たときに引っ張ってくる。この繰り返しだと思います。

### 出てきた声

「Clarityは元から見に来てくれている人が長時間見ていたりして、自分なのか競合なのか分からなくて活用できていない」という声もありました。
SNSで集客している人はまた別ですが、SEOでやっている場合はKWが肝になるので、**そのKWの検索意図を満たした記事構成・リード文になっているか**が先です。そこが満たせていれば、あとはこういう数字を見ての微調整になってきます。

逆に、自分が知らないことを言われたなら、それは新しい知識になります。

自分ならこう言いますね。「分かりました。でも◯記事までは新規で行きます。それでPVにつながらなければ、あなたの言うことを聞きます」と。AIとケンカするくらいでちょうどいいです。

## AIの分析と、自分の目の分析を突き合わせる

ここまでの手動分析と並行して、AIに8月分の月次分析を走らせておきました。

やり方は、サーチコンソールとGA4のデータを渡して「◯◯ブログの8月の分析をして」と投げるだけです。
今回は、GA4でアフィリエイトリンクのクリックが取れる設定を入れてあったので、広告クリックまで含めた「検索表示 → 検索クリック → 広告クリック」の落差も出してくれました。

出てきた内容をざっくり並べると、こんな感じでした。

*   **伸びた記事**：主力記事のクリックが28 → 59。サイト全体の57%を1本で稼いでいる
*   **新記事**：公開2週間半でクリック15・CTR13.8%を取った比較記事があり、サイト2位に入った
*   **リライトが効いた記事**：7月末にリライトした比較記事が24.6位 → 11.3位、表示回数が41 → 173
*   **表示は増えたのにクリックが取れない記事**：解約系の記事が表示91 → 294でクリック1
*   **下がった記事**：7月に伸びた2記事がクリック9 → 2に落ちた。8月18〜20日のスパムアップデートと重なるか要確認
*   **出口がない記事**：新記事16本は案件の承認待ちで、成果地点が付いていない

自分の目で見た結果と、AIの分析はおおむね同じでした。
まあ、自分が交流会で説明している考え方をそのままプロンプトに入れているので、同じ結果になるのは当たり前なんですけどね。

なので、この分析はAIに任せて時短していいと思います。
毎月同じ手順をスケジュールに組んでしまえば、自分は結果を読むだけになります。

ただし、**最終的には目視がいちばん大事**です。特に稼いでいる記事に関しては、サボらずに自分の目で見たほうがいいです。

もう1つ気づいた点として、AIも学習するので、同じモデルでも出力結果が変わってきます。たまによく分からない結果が返ってきて「元のデータはどこに置いてるんですか？」と聞かれることもあるので、AIに渡すフォルダやデータの整理も地味に大事です。

## 9月の作戦候補を5つ出して、本命を決めた

ここまでの分析をもとに、9月にやることの候補をAIに出してもらいました。

*   **A**：主力記事の広告導線を直す(検索59クリックに対して広告クリック2件、という落差を埋める)
*   **B**：下がった2記事の競合調査(上に入ってきたのが公式・比較サイト・個人ブログのどれかを確認)
*   **C**：解約系の記事のタイトル・冒頭リライト(表示294でクリック1を回収する)
*   **D**：新記事16本の出口案件探し
*   **E**：勝ち筋(比較型)の横展開KW選定

次の2週目は「この作戦を90分で実作業する回」なので、**他の人のブログでも考え方が使えるもの**を優先して選びました。

結果、**A → C → B の順**に決定。時間が余ればD・Eもやります。

AとCを先にした理由はこうです。

*   **A**：検索クリックと広告クリックの落差を1記事ずつ見ると、「読まれているのに稼いでいない記事」が一目で分かる。GA4の拡張計測は外部リンクのクリックを自動で記録するので、特別なタグはいらない
*   **C**：順位10位前後で表示だけ増えている記事は、タイトルと冒頭を直すだけで、すでにある表示からクリックを回収できる。新記事を書くより早くて確実

Aの主力記事は2週目の交流会まで触らない「交流会予約」にしておきます。先に直してしまうと、当日に見せるものがなくなってしまうので。

雑談の中で出てきた、ブログまわりの話も少しだけ。

「8月はお盆の時期に、悩み系の記事がよくクリックされてじっくり読まれた。先月は過去最大の成果だった」という方がいました。
9月に入ってパタッと止まったそうですが、**時期によって読者の悩みが変わる**のは確かにあります。夏休みならではの悩み、年末ならではの悩み。そこはアップダウンがあって当然なので、しょうがないところですね。

「AIの提案で、初めて内部リンクを付けてみた。1か月では変化なしで、経過観察と言われた」という方も。
すぐ成果が出れば理想ですが、そうはいかないので、これも検証待ちです。今まで何もやってこなかったことが「こういうことだったんだ」と分かるだけでも、自分のプラスになると思います。

## まとめ：手動で1回やったら、あとはAIとスケジュールに任せる

今回は、主催ブログの8月の数字を、ASP → サーチコンソール → Clarity → AIの月次分析の順に、その場で見ていきました。

見るポイントは、実はいつもと変わりません。

*   成果が発生している記事、ASPクリックが多い案件からテコ入れする
*   表示回数が多いのにクリックが少ない記事は、掲載順位も一緒に見る
*   記事には来ているのにリンクが押されないなら、Clarityでどこで止まっているかを見る
*   変えたら期間を決めて検証し、成功例も失敗例も引き出しにする

そして、うまくいっている記事は最優先で突っ走る。その「突っ走れる記事」を発見するのが、この振り返りの最大の目的です。

正直、手動でやると面倒くさいです。
だからこそ、1回自分の目でやって「見方」を覚えたら、あとはAIに投げて、スケジュールに組んでしまうのがおすすめです。AIが便利なのは、案件との相性まで忖度なしで教えてくれるところでもあります。

次回の2週目は9月9日(水)の朝5時から、今回決めたA → C → Bの順に、実際に記事を直していく作業を画面共有しながらやります。

「自分のブログもどこから見ればいいか分からない〜！」という方は、ぜひ交流会で一緒に数字を見ていきましょうね。
